# Station2Mac
Да... вы теперь можете управлять шорткатами с вашего Mac через свою Яндекс Станцию... что тут еще объяснять то?

# Как это устроено?
Тут есть быстрая и не большая цепочка действий: 

Говорите фразу Алисе -> Алиса распознает вашу речь -> Сама речь появляется в логах Станции -> Контроллер на вашей машине с macOS находит эту фразу -> Контроллер отменяет запрос для Алисы и отправляет UUID шортката на вашу машину -> Шорткат запускается

# Требования
> сразу скажу, это протестировано только на Станции Мини 2, работа на других Станций не гарантируется, но должно работать. ах да приложение еще и наслоплено но работает

- **Любая рутированная Яндекс Станция с доступом по Android Developer Bridge (ADB)** (https://hackalice.me/)
- **macOS Sonoma или новее**
- **Обязательно установленный ADB через Homebrew (brew install android-platform-tools)**
- Подготовленные шорткаты

# Установка
1. Скачайте ZIP [из релизов](https://github.com/tapt1c/Station2Mac/releases) и переместите в папку Applications
> у аппки нету подписи ибо я че долбоеб ебанный сто долларов на апп стор коннект отдавать этож пиздец ебанный поэтому вас может послать нахуй гейткиппер спасибо за внимание

2. Запустите
3. Вы прекрасны!

# Настройка
Дадада, вы можете вопросом задаться: "а где блядь бинарник то"

Ответ: бинарника нет ибо все построено на shell-скриптах

В приложении есть два типа подключения ADB и SSH, выбирайте какой вам удобнее.

# Теперь и о ограничениях
- **Ваша машина должна быть включена (не быть во сне!) и приложение - всегда должен стоять запущенным**
- **Автозапуск предусмотрен** - station/S99station2mac, но вы должны установить его **самостоятельно**
- Возможности управления вашей машиной через колонку ограничивается самим шорткатом, и правами, которая сама Apple дала для настройки самих шорткатов
- Само приложение поддерживается с macOS Sonoma, на Apple Silicon и Интелмаках, но было проверено пока что только на Apple Silicon с macOS Golden Gate

# Сборка с исходников (если вам вообще делать нехуй)
Скачиваете Station2Mac.xcodeproj, открываете в Xcode, выбираете схему Station2Mac и устройство My Mac, и затем Command+R

Кстати, контроллер вшит в код и создается приложением при синхронизации с колонкой.
